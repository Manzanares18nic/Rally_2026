# 🏁 Rally LATAM 2026

> Plataforma digital oficial del Rally Latinoamérica 2026

---

## 📌 Descripción

**Rally LATAM 2026** es una solución full-stack diseñada para gestionar, transmitir y vivir en tiempo real la experiencia del Rally Latinoamérica. La plataforma cubre desde la inscripción de equipos y pilotos hasta el seguimiento en vivo de etapas, clasificaciones y resultados.
